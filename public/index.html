El recetario se guarda en este móvil u ordenador. No se sube ninguna copia a la nube. Puedes importar recetas que te envíen o exportar tu colección cuando quieras.

✨ OpenAI (servidor seguro)
La app puede usar OpenAI cuando el servidor tenga configurada la variable OPENAI_API_KEY. La clave se guarda únicamente en el servidor y nunca en este navegador. OpenAI se probará primero; si no está configurado o falla, se conservará el uso de Gemini y el motor local.

Si pegas tu clave gratuita de aistudio.google.com, la app usará gemini-2.5-flash real para estructurar tus recetas dictadas. Si lo dejas vacío, funcionará con el motor inteligente integrado sin conexión.
